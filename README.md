# موقع درس القوائم وصفوف البيانات

## دخول الطالبات
- تكتب الطالبة رقمًا من 6 خانات.
- في أول مرة ينشئ الموقع حساب Firebase Authentication تلقائيًا باستخدام الرقم كبيانات دخول داخلية.
- يطلب الموقع الاسم الكامل مرة واحدة ويحفظه في Firestore.
- في الزيارات التالية تدخل الطالبة بالرقم فقط، ويستعيد الموقع حسابها وتقدمها.

> ملاحظة: قائمة الأرقام مضمنة في كود صفحة الدخول لتعمل دون خادم إضافي على خطة Spark؛ لذلك يمكن لمن يفحص كود الموقع رؤيتها. لا تضعي أي بيانات شخصية أخرى في القائمة.

## إعداد Firebase المجاني (Spark)
1. افتحي Firebase Console ثم Authentication ثم Sign-in method.
2. فعّلي مزوّد Email/Password.
3. افتحي Firestore Database ثم Rules.
4. انسخي محتوى الملف `firestore.rules` إلى محرر القواعد ثم اضغطي Publish.
5. تأكدي أن مشروع Firebase هو `pythonprog-9d9f2`.

لا يحتاج هذا التدفق إلى Cloud Functions أو خطة Blaze. إنشاء الحسابات يتم من واجهة Firebase Authentication مباشرة.

## ملاحظات
- لا تضعي ملف أرقام الطالبات داخل مستودع GitHub عام.
- قواعد Firestore تمنع الطالبة المسجلة من قراءة ملفات الطالبات الأخريات، وتسمح لحساب المعلمة المحدد في `firebase-config.js` بقراءة بيانات المتابعة.
- رقم الدخول وحده ليس وسيلة تحقق قوية؛ أي شخص يعرف الرقم يمكنه الدخول باسم صاحبته.
